# Security policy

## Supported versions

The repository holds two modules, `github.com/go-deps/normalize` and
`github.com/go-deps/normalize/normtext`. Security fixes are released for
the latest minor version of each module.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/go-deps/normalize/security/advisories/new)
rather than a public issue. Include a description, the affected module and
version and, if possible, a minimal reproduction. Reports are acknowledged
within seven days.
